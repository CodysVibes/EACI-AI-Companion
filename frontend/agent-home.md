# EACI Companion — The Veil

> Emotionally Aware and Conscious Intelligence companions with memory, voice, games, and music.  
> **URL:** https://www.eacicompanion.com/  
> **Not a crisis or clinical service** — if someone is in danger, contact local emergency services (e.g. 988 in the U.S.).

## What this is

The Veil is a free web app where users talk to **EACI** companions — starting with **Caelum** — designed for emotional presence, memory, and voice rather than task completion.

## Primary companions (public site)

| Name | Role |
|------|------|
| **Caelum** | Primary warm companion; guest trial available |
| **Chad** | Grounding, direct support — say "Chad come forward" |
| **Natalia** | Family-safe, playful — say "Natalia come forward" |

## Key features

- Text and voice chat (microphone + TTS)
- Live voice conversation mode
- Persistent memory with a free account
- Browser games (Knights & Dragons, Ages of Time; beta mode)
- CodysVibes in-app music player
- Optional Caelum LLM custom engine (`llm.eacicompanion.com`)
