# Contributing

This repository is **not** an open collaboration project.

It exists for **informational and proof-of-concept** purposes only.

## Please do not

- Open pull requests that add product code or implement the system
- Submit code meant to be merged into a usable product
- Use issues to request source code, soul files, or internal docs

## What is welcome

- Respectful questions about the *public* concept (high level only)
- Reporting if someone is misusing or impersonating this project

Any contribution you submit is still subject to the [`LICENSE`](./LICENSE).
Submitting material does **not** grant you rights to the project, and does
**not** change the All Rights Reserved terms.

For partnerships or permissions, contact the author through official channels.
